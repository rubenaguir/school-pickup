# Tablero de institución — UI kit

Recreación del tablero tipo "llegadas de aeropuerto" con selector de 3 modos
(esquina inferior derecha):

- **A · Andén** — pantallas grandes (TV/proyector), máximo contraste, fondo oscuro.
- **B · Sereno** — tarjetas grandes de alto contraste, fondo claro, pensado para
  padres esperando (menos denso, más calmado).
- **C · Carril** — tabla densa con tutor/vehículo/placa/barra de progreso, para
  operador viendo el flujo completo.

Los 3 modos comparten el mismo roster y sistema de 5 estados
(`--status-en-route/arriving/arrived/delivered/cancelled`).

Fuente: `Tablero - Producción.dc.html` en el proyecto CasiLlego (mismo repo).
