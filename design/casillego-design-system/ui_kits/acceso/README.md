# Acceso — Login y alta — UI kit

Compartido por los 3 roles (institución, tutor, operador). Flujo interactivo:
**Entrar** → **Elegir tipo de cuenta** (Escuela / Tutor) → formulario de alta
correspondiente. Panel de marca a la izquierda con mensaje de valor y ruta
animada (pin coral).

Fuente: `Acceso - Login y alta.dc.html` en el proyecto CasiLlego (mismo repo).
